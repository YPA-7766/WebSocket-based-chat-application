# WebSocket-based-chat-application
A self developed chat application that is based on sockets.io and the following stack : express.js,node.js,react.js. Its currently only on localhost as this is just a project. To connect to other users, the other user must be on the same network. Email me if you have questions or issues.

To run the program (assuming your ide or text editor is on the repo's file):
In a terminal, run the backend file using these commands:

cd backend 
npm install
npm start

In another terminal, run the frontend using the same files

cd frontend                              
npm install
npm start
